# Davood Khatar · داوود خطر

A tribute to the 1990 DOS classic *Dangerous Dave*, set across Iran.

**Play it in your browser: https://davood-khatar.github.io/**

Controls: arrows or WASD to move, ↑ / Space to jump and climb, Ctrl / X to throw
the knife, Alt / C for the flying carpet, P to pause, M for sound. On phones and
tablets, on-screen buttons appear automatically.

Ideas or bugs? Use the Feedback button in the game, or open an issue here.
